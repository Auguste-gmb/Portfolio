# Portfolio

Portfolio d'Auguste Gambu — étudiant en informatique à CESI Rouen.
Site statique (HTML, CSS, JavaScript), hébergé sur GitHub Pages : https://auguste-gmb.github.io/Portfolio/

- `index.html` — la page (une seule page avec ancres)
- `style/style.css` — styles
- `javaScript/graph.js` — graphe animé de l'accueil (Dijkstra, rayon de proximité)
- `javaScript/github-projects.js` — projets et langages chargés depuis l'API GitHub (cache 1 h)
- `javaScript/contact.js` — envoi du formulaire via Formspree
- `javaScript/navbar.js` — menu mobile
- `assets/` — icônes du site et image d'aperçu pour les partages (`og-image.png`)
- `favicon.ico`, `site.webmanifest` — icônes et manifeste
- `sitemap.xml` — à soumettre dans Google Search Console
